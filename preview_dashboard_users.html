Active Security Controls

  • Private Obscure Route: Admin access is isolated to /admin91939 with zero links or buttons on the public website.
  • Cryptographic Scrypt Hashing: Credentials are validated against salted cryptographic hashes. Plaintext passwords never exist on disk or memory.
  • Server-Side Session Guard: Enforced by HttpOnly, SameSite signed session cookies with @admin_required route guards on HTML and API routes.
  • Rate Limiting & Timing Defense: Failed attempts are throttled by IP (5 max per 10 mins) with constant-time verification and generic error responses.
